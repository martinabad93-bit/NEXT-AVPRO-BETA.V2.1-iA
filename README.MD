# NEXT AVPRO BETA V2.8 — DESKTOP

## Corrección aplicada

Se sincronizó en Desktop la misma lógica de placa corregida en Mobile.

### 1. Impuesto de Primera Placa

El cálculo de Aduanas:

- Primera Placa (17%)
- CO₂ (2%)
- Marbete

se conserva como un concepto tributario distinto y ahora **se incorpora al costo real de la operación**.

El valor se suma a:

- Total Destino
- Landed Cost
- Total Inversión
- Margen/ROI derivados del Landed

### 2. Emisión de Placa

Se mantiene separada:

- Normativa 03-25
- Placa PP
- Gestión / Endoso

**Total Emisión de Placa = Normativa + Placa PP + Gestión/Endoso.**

### 3. Pago 5

Pago 5 ahora representa el **total de Emisión de Placa convertido a USD**, no un texto fijo de RD$7,000.

La proforma conserva el desglose en RD$ y muestra el monto efectivo del Pago 5 en USD.

### 4. Sincronización

Se actualizaron los puntos principales:

- Aduanas
- Costos
- Resumen ejecutivo
- Landed
- Total Inversión
- Cronograma de pagos
- WhatsApp Proforma
- Resúmenes de impresión/AI que consumen los valores canónicos

### Regla

No se deben mezclar ni duplicar:

**Impuesto Primera Placa + CO₂ + Marbete**

con:

**Emisión de Placa = PP + Gestión/Endoso + Normativa 03-25**

Ambos conceptos entran en la inversión, pero son cargos diferentes.
