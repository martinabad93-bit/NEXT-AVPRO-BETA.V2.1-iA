# NEXT-AVPRO-BETA.V2.1

Versión Desktop/Web de NEXT GB Auto Import preparada para publicación en GitHub Pages.

## Archivos

- `index.html` — aplicación NEXT-AVPRO-BETA.V2.1.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y este `README.md` a la rama `main`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios y espera a que GitHub Pages publique el sitio.
7. Abre el enlace que GitHub muestre en la sección Pages.

## Importante

Esta versión no incluye claves privadas de API. No coloques API keys, contraseñas, tokens ni credenciales privadas dentro de `index.html` si el repositorio será público.

La versión Mobile se desarrollará posteriormente como una interfaz independiente, tomando esta versión Desktop/Web como referencia y conservando las mismas reglas de negocio.
